# Bioinformatics Notebook

A collection of Jupyter notebooks containing bioinformatics exercises, computational biology activities, and algorithm implementations completed as part of my academic coursework.

## About the Repository

This repository serves as a workspace and documentation of hands-on activities in bioinformatics. It includes implementations, visualizations, and step-by-step analyses of fundamental computational methods used in biological sequence analysis.

## Activities Covered

The notebooks in this repository may include topics such as:

- **Needleman–Wunsch Algorithm**
  - Global sequence alignment
  - Scoring matrix construction
  - Gap penalties
  - Traceback and optimal sequence alignment

- **Smith–Waterman Algorithm**
  - Local sequence alignment
  - Dynamic programming matrix
  - Identification of highly similar subsequences
  - Traceback of the best local alignment

- **DNA and Protein Sequence Analysis**
  - Sequence comparison
  - Similarity and alignment analysis
  - Basic biological sequence processing

- **Dynamic Programming in Bioinformatics**
  - Matrix initialization
  - Cell-by-cell score computation
  - Traceback procedures
  - Interpretation of alignment results

- **Bioinformatics Data Visualization**
  - Tables, matrices, plots, and graphical representations used to explain computational results

Additional activities and notebooks will be added as the course progresses.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/bioinformatics-notebook.git
cd bioinformatics-notebook
```

Create or activate a Python environment, then install the required packages:

```bash
pip install jupyter numpy pandas matplotlib
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open the desired `.ipynb` file and run the cells sequentially.
